# Asset provenance

`site/CydiaIcon.png` is the original profile picture (`pfp v7.png`) supplied by
Phoni for the site, browser icon, package fallback icon, and Sileo repository icon.
It is copied without alteration.

`tweaks/PhoniLink/Resources/Icon.png` uses that same picture, re-encoded from
the supplied WebP file into PNG for native iOS 12 compatibility. Decoded pixels
are unchanged in `Icon.png`; the `Icon60@2x.png` and `Icon60@3x.png` variants
are sized for iPhone app icons. The plain launch-screen backgrounds are generated by
`scripts/prepare_phonilink_assets.py`.

The mint palette and translucent styling are adapted from
[realphoni/home/style.css](https://github.com/realphoni/home/blob/main/style.css).
The old cube logo is retained as an unused source asset.
