# Your packages go here

Upload your built rootful `.deb` files here and commit to `main`.
The Pages workflow indexes them, creates package pages, and publishes the Sileo repo.

Use `iphoneos-arm` package architecture for iOS 12 rootful tweaks; compile the
iPhone 6 binary for `arm64`. `iphoneos-arm64` is the rootless package architecture
and is rejected here. No spaces in filenames. Increase `Version` for updates.

The main [README](../README.md) has the full publishing instructions.
